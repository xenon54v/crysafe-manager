# Руководство пользователя CryptoSafe Manager

## 1. Установка и запуск

### Из исходного кода

1. Установите Python 3.12.
2. Создайте виртуальную среду: `python -m venv .venv`.
3. Активируйте её и выполните `python -m pip install -r requirements.txt`.
4. Проверьте установку командой `python run.py --check`.
5. Запустите приложение командой `python run.py`.

### Из готовой Linux-сборки

1. Распакуйте `CryptoSafeManager-linux-x86_64.zip`.
2. Сохраните папку `CryptoSafeManager` целиком.
3. Выдайте право на запуск: `chmod +x CryptoSafeManager/cryptosafe-manager`.
4. Выполните `./CryptoSafeManager/cryptosafe-manager --check`.
5. Запустите `./CryptoSafeManager/cryptosafe-manager`.

## 2. Создание мастер-пароля и хранилища

При первом запуске откроется мастер настройки.

1. Введите мастер-пароль длиной не менее 12 символов.
2. Используйте строчные и заглавные буквы, цифру и специальный символ.
3. Повторите пароль.
4. Выберите путь к файлу хранилища или оставьте предложенный.
5. Проверьте выбранные параметры и завершите настройку.

![Мастер создания хранилища](images/setup.png)

Мастер-пароль нельзя восстановить из БД. Храните его отдельно. Приложение сохраняет Argon2id-хеш для проверки и выводит ключ шифрования через PBKDF2 с индивидуальной солью.

## 3. Вход и блокировка

Введите мастер-пароль в окне входа. После нескольких неверных попыток задержка увеличивается. Команда `Security → Lock` блокирует хранилище вручную. Автоматическая блокировка срабатывает после периода бездействия и при обнаружении блокировки экрана, если это поддерживает ОС.

## 4. Добавление записи

1. Нажмите `Add` или `Ctrl+N`.
2. Заполните название и пароль. Имя пользователя и URL необязательны.
3. Для нового пароля нажмите `Generate` и задайте длину и используемые группы символов.
4. Проверьте индикатор стойкости.
5. При необходимости добавьте категорию, теги и заметки.
6. Нажмите `Save`.

![Добавление записи](images/entry_editor.png)

Приложение проверит обязательные поля и URL. Запись шифруется до помещения в SQLite.

## 5. Просмотр, поиск и редактирование

![Главное окно хранилища](images/vault_overview.png)

- Введите текст в строку поиска, чтобы найти совпадение по названию, имени, URL, заметкам и тегам.
- Для точного поля используйте `title:`, `username:`, `url:`, `notes:`, `category:` или `tag:`.
- Выберите строку и нажмите `Edit`, чтобы изменить запись.
- Нажмите `Delete`, чтобы выполнить мягкое удаление. Запись остаётся в зашифрованной корзине до окончания срока очистки.
- Кнопка `Show Passwords` временно раскрывает пароли в таблице. Перед блокировкой и выходом интерфейс очищает эти значения.

## 6. Защищённый буфер обмена

1. Выберите запись и скопируйте пароль через контекстное меню или действие копирования.
2. Проверьте таймер в строке состояния.
3. Вставьте значение в нужное приложение до окончания таймера.
4. Для немедленной очистки нажмите `Clear Clipboard`.

![Состояние защищённого буфера](images/secure_clipboard.png)

Перед новой операцией копирования приложение очищает предыдущий секрет. Очистка также выполняется при блокировке, выходе, закрытии и panic mode. Если другое приложение изменило буфер, CryptoSafe Manager не стирает чужое новое значение.

## 7. Экспорт

1. Откройте `File → Export`.
2. Выберите все записи или отметьте нужные.
3. Для резервной копии выберите CryptoSafe JSON и AES-256-GCM.
4. Введите отдельный экспортный пароль. Не используйте мастер-пароль.
5. Исключите поля, которые не должны попасть в файл.
6. Проверьте предварительный результат и сохраните файл.

![Настройки экспорта](images/encrypted_export.png)

CSV и форматы сторонних менеджеров могут быть открытым текстом. Приложение требует явное подтверждение такого экспорта.

## 8. Импорт

1. Откройте `File → Import` и выберите файл.
2. При необходимости введите пароль или укажите закрытый ключ.
3. Просмотрите найденный формат, количество записей и предупреждения.
4. Выберите режим `Merge` для добавления или `Replace` для полной замены.
5. Настройте обработку дубликатов.
6. Выполните импорт.

Импорт работает в транзакции. При ошибке обычный режим откатывает изменения. Для крупного файла доступен возобновляемый частичный режим.

## 9. Передача отдельных записей

Окно `Share` создаёт ограниченный пакет одной записи. Можно исключить имя пользователя, пароль, URL или заметки, установить срок от 1 до 30 дней и выбрать пароль, RSA или ECC. Получатель использует `Receive Share`. Проверяйте отпечаток контактного ключа по независимому каналу.

## 10. Журнал аудита

Откройте `Tools → Audit logs`.

![Просмотр журнала аудита](images/audit_log.png)

- `Verify full chain` проверяет порядок записей, предыдущие хеши, подписи и подписанный head-якорь.
- Фильтры ограничивают события по типу, времени, уровню и пользователю.
- Экспорт журнала доступен в JSON, CSV и PDF. Для интерактивного экспорта требуется подтверждение мастер-пароля.
- Красный статус целостности означает, что приложение обнаружило изменение или усечение журнала. Заблокируйте хранилище и сохраните БД для расследования.

## 11. Panic mode

Panic mode запускается из меню, трея, настроенной горячей клавишей или жестом встряхивания окна. Обработчики выполняются в безопасном порядке: очищают системный буфер и защищённую память, скрывают окно, блокируют ключи и хранилище. Повторный запуск не дублирует очистку. Для восстановления требуется правильный мастер-пароль.

## 12. Резервное копирование и восстановление

Используйте зашифрованный экспорт CryptoSafe JSON для переносимой резервной копии. Дополнительно можно сохранить копию файла SQLite при закрытом приложении. Не заменяйте рабочую БД непроверенной копией. После восстановления выполните полную проверку журнала аудита.

## 13. Решение проблем

| Проблема | Действие |
|---|---|
| Приложение не запускается | Выполните `python run.py --check` или `cryptosafe-manager --check` и проверьте `cryptosafe.log` в каталоге данных |
| Буфер не работает в Linux | Установите `wl-clipboard`, `xclip` или `xsel` для используемой графической сессии |
| Трей не отображается | Проверьте поддержку системного трея в окружении рабочего стола; основное окно продолжает работать |
| Мастер-пароль не подходит | Проверьте раскладку и регистр; обхода или восстановления пароля нет |
| Импорт отклонён | Проверьте формат, пароль, размер, целостность и срок действия пакета |
| Аудит показывает нарушение | Не продолжайте обычную работу, заблокируйте хранилище и сохраните копию БД |

## 14. Безопасное завершение

Используйте `File → Exit`. Приложение очищает буфер, защищённые объекты и активные ключи, останавливает фоновые потоки и закрывает пул SQLite. Принудительное завершение ОС не может гарантировать выполнение всех обработчиков, поэтому системный swap и дампы процесса должны быть защищены средствами ОС.
